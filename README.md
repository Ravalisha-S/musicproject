Music Player

A simple and interactive music player built using HTML, CSS and JavaScript.

The music player allows users to play songs, control playback, adjust volume, view song progress and select songs from a playlist.

Features

- Play and pause songs
- Previous and next song controls
- Song title and artist display
- Interactive progress bar
- Current playback time display
- Total song duration display
- Volume control
- Playlist support
- Automatic next song playback
- Clickable playlist items
- Dark-themed user interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Audio API

How to Use

1. Open the "Music.html" file in a web browser.
2. Add the required music files to the project folder.
3. Make sure the file names match the names used in the JavaScript code.
4. Use the Play/Pause button to control playback.
5. Use Previous and Next buttons to change songs.
6. Use the progress bar to move through the song.
7. Adjust the volume using the volume control.
8. Select a song directly from the playlist.
